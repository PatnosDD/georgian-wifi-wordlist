This repository offers a thorough wordlist specifically designed for WiFi passwords frequently found in Georgia.

## File Contents

The primary file is `geowifi-wordlist.txt`, which is approximately 11MB in size. This single, comprehensive wordlist is intended for WiFi auditing or educational penetration testing within a Georgian context.

## Important Disclaimer

This project is intended solely for educational use and authorized testing. It must not be used for any unauthorized access or illegal activities. Always ensure you have explicit permission before conducting any network testing.

## Usage Tip

This wordlist can be effectively used with tools such as `aircrack-ng`, `hashcat`, or `wifite` to facilitate dictionary attacks against networks.
